# Kelola Tamu

Menu **Kelola Tamu** digunakan untuk mengatur seluruh daftar tamu undangan dalam satu tempat.

Buka **Data Tamu → Semua Tamu** untuk mulai mengelola tamu.

## Ringkasan Data Tamu

Pada bagian atas halaman tersedia informasi untuk memantau data tamu dan pengiriman undangan.

- **Kuota WA Official Blast** — kuota tersedia, terpakai, dan sisa kuota.
- **Status Pengiriman WA Blast** — status Sent, Delivered, Read, dan Failed.
- **Statistik Tamu** — total tamu, konfirmasi hadir, belum konfirmasi, tidak hadir, dan perkiraan akan hadir.

<Info>
  Format **Tamu / Pax** menunjukkan jumlah data undangan dan jumlah orang yang tercakup dalam undangan tersebut.
</Info>

## Tambah Tamu

Gunakan fitur **Tamu** untuk menambahkan tamu satu per satu.

<Steps>
  <Step title="Buka form Tambah Tamu">
    Klik tombol **Tamu** pada halaman Data Tamu.
  </Step>
  <Step title="Lengkapi data tamu">
    Isi informasi berikut:

    - **Nama Tamu** — wajib diisi.
    - **No. WhatsApp** — opsional.
    - **Kategori** — Regular, VIP, atau VVIP.
    - **Group** — pilih Group atau Tanpa Group.
    - **Jumlah Tamu** — jumlah orang dalam undangan.
    - **Keterangan** — catatan tambahan jika diperlukan.
  </Step>
  <Step title="Simpan">
    Klik **Simpan** untuk menambahkan tamu ke daftar.
  </Step>
</Steps>

<Info>
  Untuk nomor Indonesia, pilih **\+62** lalu masukkan nomor tanpa `0` di depan.

  Contoh: `081234567890` menjadi `81234567890`.
</Info>

## Import Tamu

Gunakan **Import** untuk menambahkan banyak tamu sekaligus melalui file Excel.

<Steps>
  <Step title="Download Template">
    Klik **Import → Download Template**, kemudian isi data sesuai format yang tersedia.
  </Step>
  <Step title="Upload File">
    Pilih file Excel dengan format `.xls` atau `.xlsx`.
  </Step>
  <Step title="Mulai Import">
    Klik **Import Sekarang** dan tunggu hingga proses selesai.
  </Step>
</Steps>

<Warning>
  Maksimal **500 tamu dalam satu kali import**. Jangan refresh halaman selama proses berlangsung.
</Warning>

{/* Screenshot: Import Data Tamu */}

### Import Contact

Gunakan **Import Contact** untuk menambahkan tamu dari daftar kontak.

Klik **Import Contact**, pilih kontak yang dibutuhkan, kemudian ikuti proses yang ditampilkan.

{/* Screenshot: Import Contact */}

## Kelola Group

Fitur **Group** digunakan untuk mengelompokkan tamu agar daftar lebih mudah dikelola.

Contoh:

- Keluarga Mempelai
- Teman Kantor
- Teman Sekolah
- Instansi
- Komunitas

Klik **Group** untuk membuka pengelolaan Group.

Group dapat digunakan saat **Tambah Tamu**, **Edit**, **Filter**, **Bulk Edit**, dan **Export PDF**.

<Tip>
  Jika memiliki banyak tamu, buat Group terlebih dahulu sebelum melakukan import.
</Tip>

## Daftar Tamu

Data tamu ditampilkan dalam tabel dengan informasi utama berikut.

| Kolom | Keterangan |
| --- | --- |
| **Kode** | Kode unik dan akses E-Invitation |
| **Nama** | Nama penerima undangan |
| **WhatsApp** | Nomor WhatsApp tamu |
| **Kategori** | Regular, VIP, atau VVIP |
| **Group** | Kelompok tamu |
| **Meja** | Penempatan meja |
| **Keterangan** | Catatan tambahan |
| **Konfirmasi** | Status konfirmasi tamu |
| **Pax** | Jumlah orang dalam undangan |
| **Status Blast** | Status pengiriman pesan |
| **Actions** | Tindakan untuk tamu |

## Cari dan Filter Tamu

### Cari Tamu

Gunakan kolom **Cari Tamu...** untuk menemukan tamu dengan cepat berdasarkan nama.

### Filter

Klik **Filter** untuk menyaring daftar berdasarkan:

- **Kategori** — Regular, VIP, atau VVIP.
- **Group** — Group tertentu.
- **Status Blast** — Terkirim, Pending/Processing, Gagal, Dilewati, atau Belum Dikirim.
- **Konfirmasi** — Sudah Konfirmasi atau Belum Konfirmasi.
- **RSVP** — Hadir atau Tidak Hadir.

Klik **Filter** untuk menerapkan pilihan atau **Reset** untuk kembali menampilkan seluruh data.

<Tip>
  Filter dapat dikombinasikan, misalnya **VIP \+ Belum Konfirmasi**.
</Tip>

## Aksi pada Tamu

Setiap tamu memiliki menu **Actions** untuk melakukan tindakan secara individual.

<AccordionGroup>
  <Accordion title="Kirim / Kirim Ulang">
    Gunakan **Kirim** untuk mengirim undangan kepada tamu.

    Jika sudah pernah dikirim, tersedia opsi **Kirim Ulang**.
  </Accordion>

  <Accordion title="Share">
    Gunakan **Share** untuk membagikan undangan secara manual melalui opsi berbagi yang tersedia.
  </Accordion>

  <Accordion title="Edit">
    Gunakan **Edit** untuk memperbarui nama, nomor WhatsApp, kategori, Group, jumlah tamu, atau keterangan.

    Klik **Update** untuk menyimpan perubahan.
  </Accordion>

  <Accordion title="Buka Undangan">
    Klik **Buka Undangan** untuk melihat halaman undangan milik tamu tersebut.
  </Accordion>

  <Accordion title="Hapus">
    Gunakan **Hapus** untuk menghapus tamu dari daftar.
  </Accordion>
</AccordionGroup>

<Warning>
  Pastikan data yang dipilih sudah benar sebelum melakukan penghapusan.
</Warning>

## Kelola Beberapa Tamu

Centang satu atau beberapa tamu untuk melakukan tindakan secara massal.

Jumlah tamu yang dipilih akan terlihat pada indikator **Selected**.

Tindakan yang tersedia:

- **WhatsApp Blast**
- **E-Invitation**
- **Edit**
- **Delete**

Gunakan **Select All** untuk memilih seluruh tamu yang sedang ditampilkan.

{/* Screenshot: Bulk Action */}

### Bulk Edit

<Steps>
  <Step title="Pilih Tamu">
    Centang tamu yang ingin diperbarui.
  </Step>
  <Step title="Klik Edit">
    Pilih **Edit** pada menu tindakan massal.
  </Step>
  <Step title="Tentukan Perubahan">
    Pilih **Kategori** dan/atau **Group** yang ingin diterapkan.
  </Step>
  <Step title="Simpan">
    Klik **Simpan** untuk menerapkan perubahan.
  </Step>
</Steps>

### Bulk Delete

Pilih beberapa tamu kemudian klik **Delete** untuk menghapus seluruh data yang dipilih.

<Warning>
  Periksa jumlah **Selected** sebelum menjalankan Edit atau Delete massal.
</Warning>

## Generate E-Invitation

Gunakan **E-Invitation** untuk membuat undangan beberapa tamu sekaligus.

<Steps>
  <Step title="Pilih Tamu">
    Centang tamu yang ingin dibuatkan E-Invitation.
  </Step>
  <Step title="Klik E-Invitation">
    Pilih kategori **Semua**, **Regular**, **VIP**, atau **VVIP**.
  </Step>
  <Step title="Download">
    Klik **Download (V2)** dan tunggu proses generate selesai.
  </Step>
</Steps>

<Info>
  Untuk satu tamu, gunakan **Kode/QR → Preview E-Invitation → Download E-Invitation**.
</Info>

## Edit Template WA Manual

Klik **Edit Template WA Manual** untuk mengatur isi pesan saat membagikan undangan secara manual.

Variabel yang tersedia:

| Variabel | Fungsi |
| --- | --- |
| `[NAMA-TAMU]` | Menampilkan nama tamu otomatis |
| `[LINK-UNDANGAN]` | Menampilkan link undangan tamu |

Contoh:

```text
Kepada Yth.
*[NAMA-TAMU]*

Berikut link undangan Anda:
[LINK-UNDANGAN]
```

Klik **Simpan** setelah selesai.

<Warning>
  Jangan mengubah format `[NAMA-TAMU]` dan `[LINK-UNDANGAN]` agar variabel tetap dapat diproses sistem.
</Warning>

## Export PDF

Gunakan **Export PDF** untuk mengunduh daftar tamu dalam bentuk PDF.

Data dapat disaring berdasarkan:

- **Status RSVP**
- **Kategori**
- **Group**

<Steps>
  <Step title="Klik Export PDF">
    Buka menu **Export PDF**.
  </Step>
  <Step title="Pilih Data">
    Tentukan Status RSVP, Kategori, dan Group sesuai kebutuhan.
  </Step>
  <Step title="Download">
    Klik **Download PDF**.
  </Step>
</Steps>

<Tip>
  Contoh: pilih **RSVP: Hadir** dan **Kategori: VIP** untuk membuat daftar tamu VIP yang hadir.
</Tip>

## Navigasi Daftar

Gunakan navigasi pada bagian bawah tabel untuk berpindah halaman atau mengatur jumlah data.

- **Prev** — halaman sebelumnya.
- **Next** — halaman berikutnya.
- **Tampilkan** — jumlah data per halaman.

Pilihan jumlah data:

`10` · `20` · `50` · `100`
